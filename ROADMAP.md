# Roadmap

This roadmap states intended research and engineering directions, not delivery promises. Security, privacy, licensing, and evidence quality take priority over breadth.

## Release 0.1.x

- Complete human IP, patent, privacy, secret, and dependency-license review.
- Stabilize request/provider/memory interfaces while preserving safe defaults.
- Expand negative tests for session ownership, SSE, prompt injection, provider failure, and sensory isolation.
- Improve deterministic evidence manifests and cross-platform reproduction.
- Document supported Ollama/provider combinations using reproducible, non-endorsement test records.
- Resolve or narrow optional dependency/license questions.

## Candidate 0.2 Work

- Define versioned DIM and SAL schemas from observed public use cases.
- Add explicit memory consent, inspection, export, and deletion controls before broader persistence use.
- Strengthen process isolation and capability policy for any future tool integrations.
- Expand EAS pack provenance records and independent calculation-validation fixtures.
- Add SIS experiment-record interfaces without claiming automated novelty or patent clearance.
- Evaluate accessible CSC controls and local transcription options while retaining explicit consent and no-retention defaults.

## Longer-Term Research

- Reproducible comparisons between deterministic adjudication and probabilistic planning.
- Provenance-aware retrieval and context-conflict handling.
- Formalized governance invariants and failure taxonomies.
- Independent security assessment and threat-model validation.
- Carefully scoped multi-user deployment architecture only after identity, authorization, retention, and abuse controls are designed and reviewed.

## Non-Goals

The roadmap does not target consciousness, sentience, AGI claims, unrestricted autonomous operation, replacement of licensed professionals, automated patent clearance, covert sensory collection, or production deployment before appropriate controls and validation exist.
