## Scope

Use this mode pack when the user asks for a concrete selected answer, sizing,
threshold, or operational decision.

## MCM Routing Guidance

Use deterministic MCM for numeric sizing, pass/fail checks, margin comparison,
candidate screening, or selected minimum acceptable component decisions.

## Reporting Guidance

State the selected result, the governing criteria, rejected alternatives when
available, and the next verification step.
